使用文档

识别规则 · 判定逻辑 · 风险等级 · 适用场景，以及这个工具做不到的地方。

一句话说明：隐私哨兵是一个敏感信息检测工具。你把文本、图片、音频或视频交给它， 它找出其中可能泄露的隐私字段，告诉你为什么危险、该怎么处理，并给出脱敏后的版本。

1. 三步开始使用

  1. 粘贴内容：在输入框里粘贴一段文字，或点击 📎 上传图片 / 音频 / 视频。
  2. 查看报告：点击发送后会自动检测，给出风险评分、风险清单和整改建议。
  3. 一键处理：复制脱敏后的文本，或导出 JSON 报告留存。

不确定效果？点首页的 ✨ 填示例，会自动填入一段示例文本，点发送即可看到完整报告。

2. 支持识别的类型

下表是全部内置规则。等级是该类型的最低判定等级，实际等级会结合上下文上调。

类型等级判定方式说明
身份证号L1 格式 + 日期校验 + GB 11643 校验位 18 位校验位通过才算确认；15 位老号无校验位，标为「存疑」
银行卡号L2 发卡行前缀 + Luhn 校验 首位必须是 3/4/5/6，否则不判定为卡号，可滤掉大量随机长数字
手机号L1 号段匹配（1[3-9] 开头 11 位） 中国大陆号段
密码L3 上下文关键词（密码 / password / pwd 等） 需出现关键词才判定，避免把任意字符串当成密码
短信验证码L4 上下文关键词 + 4~8 位数字 前后两种语序都支持（「验证码 8832」和「8832 是验证码」）
API 密钥L3 厂商前缀特征 + 上下文声明 覆盖 OpenAI、AWS、阿里云、腾讯云、GitHub、GitLab、Slack、Stripe、JWT、PEM 私钥头等
家庭住址L1 城市名 + 路 / 街 / 小区 / 号等后缀 支持国内主要城市
电子邮箱L1 RFC 宽松格式匹配 —
链接地址L1 URL 格式匹配 会检查 query 中是否含 token / code 等凭据
护照号L1 上下文 + E/G/D 前缀 需出现「护照」等关键词，避免误伤产品序列号
统一社会信用代码L2 上下文 + ISO 7064 MOD 31-3 校验 GB 32100-2015

3. 判定逻辑：两条通道如何配合

工具同时运行两套引擎，结果融合后输出：

① 本地规则引擎（始终运行）

纯正则 + 校验算法，在服务端本地完成，不依赖任何外部服务。 优点是快（毫秒级）、结果确定、逐字符准确；缺点是只能识别格式固定的信息。

② AI 语义引擎（文本 / 图片 / 音视频）

调用多模态模型理解语义，能识别姓名、话术风险、图片中的证件等「没有固定格式」的敏感信息。 优点覆盖面广；缺点是慢、有成本，且可能出现幻觉。

融合策略

  • 本地命中优先，保证 raw 逐字符准确（模型可能抄错数字）；
  • 模型补出的新条目合并进来，标注来源；
  • 同一位置冲突时，按「校验通过 > 证据强度 > 覆盖长度」取舍，避免一串数字被报成两类；
  • 模型挂掉时自动退回纯本地结果，并明确提示「当前结果来自本地规则引擎」——不假装一切正常。

4. 风险等级

等级含义典型场景
L1 低危可识别到个人，但单独泄露危害有限手机号、邮箱、住址
L2 中危可用于金融操作或主体冒用银行卡号、统一社会信用代码
L3 高危可直接导致账号被接管明文密码、API 密钥
L4 极高危可用于完成支付或身份冒用，时效性极强短信验证码

风险评分是 100 分制的直观换算：无风险 100 分，等级越高、条数越多，扣分越多，最低 5 分。 它只是为了让非技术用户一眼看出严重程度，不代表精确的数学概率。

6. 适用场景

  • 发送聊天消息、邮件前，检查有没有把身份证号、卡号发出去；
  • 截图分享前，检查图片里有没有证件、手机号、住址；
  • 提交代码 / 配置文件前，检查有没有把 API 密钥、数据库密码写进去；
  • 批量检查一批文本（如客服记录、日志、表单导出）中的敏感字段；
  • 给家人（尤其是长辈）做一次「这条消息能不能发」的确认。
能力边界（请务必了解）
  • 它不是杀毒软件，也不是合规审计工具。它能降低「不小心发出去」的概率， 不能保证 100% 不漏报。涉及合同、公文、对外发布的内容，仍需人工复核。
  • 图片识别依赖模型，手写体、严重模糊、强反光、极小字号可能识别不出。
  • 只识别中国大陆的号码规则。境外身份证、护照格式、国际银行卡覆盖有限。
  • 姓名识别准确率有限：中文姓名没有固定格式，模型可能把普通词语误判为姓名， 也可能漏掉不常见的姓名。
  • 不要用它检测他人的隐私信息。工具设计目的是保护你自己的信息， 拿来批量扫描他人数据既不合适也可能违法。

7. 隐私承诺

  • 提交的内容仅用于本次检测，检测完成后服务端不保留原始数据。
  • 不转发给第三方，不出售，不用于模型训练。
  • 结果中的敏感字段默认脱敏展示，完整原文不回传页面。
  • 音频检测所需的临时文件，转写完成后立即从对象存储删除。
  • 登录仅用于同步你自己的历史记录，密码以 scrypt 哈希存储。
  • 全站启用 HTTPS 与安全响应头（CSP / HSTS / nosniff），不投放第三方追踪脚本。

本项目开源，你可以自行审计源码确认以上承诺。若你使用的是他人部署的实例， 承诺由该实例的部署配置决定。

8. 常见问题

为什么第一次访问要等十几秒？

服务部署在按需运行的实例上，长时间无人访问后会自动休眠。首次访问需要冷启动， 通常会看到「服务正在唤醒」的提示，等待 15~30 秒后自动重试即可。

检测会花钱吗？

本地规则引擎完全免费且不限次。只有调用 AI 语义引擎（文本复检、图片、音视频）才有成本， 由服务提供方承担。批量检测默认走本地引擎，不消耗 AI 额度。

可以只检测某几类信息吗？

可以。点首页的 🎛 检测规则，勾选你关心的类型，未勾选的会完全跳过检测。

结果能保存吗？

最近一次检测结果会存在浏览器本地（localStorage），刷新页面不丢失，24 小时后自动失效。 登录后可同步到云端。也可以导出 JSON 或复制报告文本自行保存。

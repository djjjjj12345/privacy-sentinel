使用文档

识别规则 · 判定逻辑 · 风险等级 · 适用场景，以及这个工具做不到的地方。

一句话说明：隐私哨兵是一个敏感信息检测工具。你把文本、图片、音频或视频交给它， 它找出其中可能泄露的隐私字段，告诉你为什么危险、该怎么处理，并给出脱敏后的版本。

1. 三步开始使用

  1. 粘贴内容：在输入框里粘贴一段文字，或点击 📎 上传图片 / 音频 / 视频。
  2. 查看报告：点击发送后会自动检测，给出风险评分、风险清单和整改建议。
  3. 一键处理：复制脱敏后的文本，或导出 JSON 报告留存。

不确定效果？点首页的 ✨ 填示例，会自动填入一段示例文本，点发送即可看到完整报告。

3. 判定逻辑：两条通道如何配合

工具同时运行两套引擎，结果融合后输出：

① 本地规则引擎（始终运行）

纯正则 + 校验算法，整份规则会下发到浏览器，因此纯文本检测可以完全在你的设备上完成（见下一节）。 优点是快（毫秒级）、结果确定、逐字符准确；缺点是只能识别格式固定的信息。

② AI 语义引擎（文本 / 图片 / 音视频）

调用多模态模型理解语义，能识别姓名、话术风险、图片中的证件等「没有固定格式」的敏感信息。 优点覆盖面广；缺点是慢、有成本，且可能出现幻觉。

融合策略

  • 本地命中优先，保证 raw 逐字符准确（模型可能抄错数字）；
  • 模型补出的新条目合并进来，标注来源；
  • 同一位置冲突时，按「校验通过 > 证据强度 > 覆盖长度」取舍，避免一串数字被报成两类；
  • 模型挂掉时自动退回纯本地结果，并明确提示「当前结果来自本地规则引擎」——不假装一切正常。

4. 本地模式：原文不出浏览器

首页顶部有一个默认开启的开关：🔒 本地模式：开。开启时，纯文本检测完全在浏览器里完成， 不会发起任何网络请求，粘贴的身份证、银行卡、密钥不会被发送到服务器——包括我们自己的服务器。

两种模式的区别

对比项🔒 本地模式（默认）☁️ 云端双引擎
原文是否上传不上传，只在本机内存处理上传到服务端做语义识别
识别范围格式固定的字段：证件号、手机号、银行卡、邮箱、IP、密钥、验证码、住址等额外识别姓名、话术诱导、图片/音视频中的证件
速度毫秒级，离线可用受网络与模型影响，通常 1~5 秒

开关状态会被记住。本地模式未命中时，页面会明确提示「语义类风险需要云端模型」，不会假装已经查全。

5. 风险等级

等级含义典型场景
L1 低危可识别到个人，但单独泄露危害有限手机号、邮箱、住址
L2 中危可用于金融操作或主体冒用银行卡号、统一社会信用代码
L3 高危可直接导致账号被接管明文密码、API 密钥
L4 极高危可用于完成支付或身份冒用，时效性极强短信验证码

风险评分是 100 分制的直观换算：无风险 100 分，等级越高、条数越多，扣分越多，最低 5 分。 它只是为了让非技术用户一眼看出严重程度，不代表精确的数学概率。

置信度与「疑似示例值」

每条结果都会标出判断依据，避免把测试数据当成真泄露、或把真泄露当成测试数据：

  • ✓ 校验通过：身份证校验位、银行卡 Luhn 校验通过，基本可判定为真实格式；
  • ⚠ 校验位不符：格式像但校验不过，多为手输错误或测试号码，仍会上报但提示人工确认；
  • 语义推断 xx%：来自 AI 语义识别，无校验依据；
  • 疑似示例值：命中 13800138000、example.com 这类常见占位值。

抗变形处理

以下常见「绕过写法」都会被还原后再匹配，仍能识别：零宽字符插入（13​800138000）、 全角数字（１３８００１３８０００）、号码内空格或连字符（138 0013-8000）。 注意：点号不会被折叠，否则 192.168.1.100 会被粘成一串数字而漏检 IP。

7. 适用场景

  • 发送聊天消息、邮件前，检查有没有把身份证号、卡号发出去；
  • 截图分享前，检查图片里有没有证件、手机号、住址；
  • 提交代码 / 配置文件前，检查有没有把 API 密钥、数据库密码写进去；
  • 批量检查一批文本（如客服记录、日志、表单导出）中的敏感字段；
  • 给家人（尤其是长辈）做一次「这条消息能不能发」的确认。
能力边界（请务必了解）
  • 它不是杀毒软件，也不是合规审计工具。它能降低「不小心发出去」的概率， 不能保证 100% 不漏报。涉及合同、公文、对外发布的内容，仍需人工复核。
  • 图片识别依赖模型，手写体、严重模糊、强反光、极小字号可能识别不出。
  • 只识别中国大陆的号码规则。境外身份证、护照格式、国际银行卡覆盖有限。
  • 姓名识别准确率有限：中文姓名没有固定格式，模型可能把普通词语误判为姓名， 也可能漏掉不常见的姓名。
  • 不要用它检测他人的隐私信息。工具设计目的是保护你自己的信息， 拿来批量扫描他人数据既不合适也可能违法。

8. 隐私承诺

  • 提交的内容仅用于本次检测，检测完成后服务端不保留原始数据。
  • 不转发给第三方，不出售，不用于模型训练。
  • 结果中的敏感字段默认脱敏展示，完整原文不回传页面。
  • 音频检测所需的临时文件，转写完成后立即从对象存储删除。
  • 登录仅用于同步你自己的历史记录，密码以 scrypt 哈希存储。
  • 全站启用 HTTPS 与安全响应头（CSP / HSTS / nosniff），不投放第三方追踪脚本。

本项目开源，你可以自行审计源码确认以上承诺。若你使用的是他人部署的实例， 承诺由该实例的部署配置决定。

9. 常见问题

为什么第一次访问要等十几秒？

服务部署在按需运行的实例上，长时间无人访问后会自动休眠。首次访问需要冷启动， 通常会看到「服务正在唤醒」的提示，等待 15~30 秒后自动重试即可。

检测会花钱吗？

本地规则引擎完全免费且不限次。只有调用 AI 语义引擎（文本复检、图片、音视频）才有成本， 由服务提供方承担。批量检测默认走本地引擎，不消耗 AI 额度。

可以只检测某几类信息吗？

可以。点首页的 🎛 检测规则，勾选你关心的类型，未勾选的会完全跳过检测。

结果能保存吗？

最近一次检测结果会存在浏览器本地（localStorage），刷新页面不丢失，24 小时后自动失效。 登录后可同步到云端。也可以导出 JSON 或复制报告文本自行保存。

10. 接入到自己的系统（API）

页面用到的就是同一个公开接口，可以直接集成进 CI、浏览器插件或内部系统：

curl -X POST https://privacy-sentinel.onrender.com/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"kind":"text","text":"手机号 13800138000","mode":"local"}'

关键字段：

字段说明
kindtext / image / audio / video
modelocal 只跑规则引擎（免费、毫秒级）；省略则双引擎
types数组，只检测指定类型；null 表示全量
items[]每条含 type / label / masked / level / verified / confidence / start / end
code错误分类码，如 invalid_url、rate_limited，便于程序分支

批量检测：POST /api/analyze/batch，请求体 {"items":[{"text":"..."}]}，单批上限 50 条。 接口默认限流 30 次 / 分钟，响应头带 X-RateLimit-Remaining。

11. 明确不支持的事

写在这里是为了不夸大能力——以下场景目前做不到，请勿依赖：

  • 不能解析 PDF / Word / Excel 文档：把文档内容复制成文本再粘贴，或先导出为图片；
  • 不能判断凭证是否真实可用：只做格式与校验位判断，不会去调用密钥验证它的有效性（那本身就是危险操作）；
  • 不能保证 100% 不漏检：正则是确定性规则，语义类风险依赖模型，两者都有边界；
  • 不能替代合规审计：它是发送前的自查工具，不是数据合规扫描平台；
  • 音视频检测依赖模型：需要联网，且长音视频可能超时，建议 1 分钟以内。

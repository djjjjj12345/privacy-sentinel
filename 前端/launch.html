  • 导出 JSON / 报告文本 / 脱敏后文本

适合：写完一大段要发的内容、检查配置文件、批量排查历史消息。

隐私哨兵 · 输入守卫

边写边提醒 → 一键脱敏

  • 在任意网站的输入框、评论区实时检测
  • 命中即浮出提醒条，一键打码 / 替换 / 删除
  • 发布前对高危项二次确认
  • 阈值可调：从「全都提醒」到「只拦高危」
  • 按站点静音，不打扰你常用的地方

适合：在微博、知乎、招聘网站、二手平台随手打字时的最后一道防线。

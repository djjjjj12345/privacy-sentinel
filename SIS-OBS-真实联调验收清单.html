隐私哨兵 · SIS + OBS 真实联调验收清单

把「代码链路已通」推进到「真实云资源跑通一次」——开通 SIS、建 OBS 桶、填 7 个变量、跑通真实录音、确认无残留。

预计 30–40 分钟 需要：已实名华为云账号 SIS 有免费额度OBS 标准存储约 ¥0.099/GB/月

0开始前必须知道的三件事

  1. 区域规则：MaaS 只在「西南-贵阳一」，但 SIS 与 OBS 可以选别的区域——唯一硬约束是 SIS 与 OBS 必须同区域。本清单统一用 华北-北京四 cn-north-4。
  2. 不要用主账号 AK：在 IAM 里建一个子账号，只授予 SIS FullAccess 和 OBS Buckets Viewer/Editor，用它的 AK/SK。泄露时影响面可控。
  3. 桶必须私有：音频是高度敏感数据，绝不开启公共读。代码里转写完成会立刻删除对象，另建议配生命周期兜底。

1开通 SIS 语音交互服务

控制台 → 左上角「服务列表」 → 人工智能 > 语音交互服务 SIS → 开通服务
  1. 区域下拉选 华北-北京四（若页面让你选项目，保持默认）。
  2. 点「开通 / 立即使用」，不需要额外审批，即时生效。免费额度通常按分钟给，够做几十次验证。
  3. 开通后记住端点：https://sis-ext.cn-north-4.myhuaweicloud.com（注意是 sis-ext，不是 sis），这就是 HW_SIS_ENDPOINT。
如果列表里找不到 SIS，直接在控制台顶部搜索框输入「语音交互」或「SIS」即可。

⚠️ 还要单独开通「录音文件识别极速版」

SIS 控制台 → 顶部页签「录音文件识别极速版」 → 卡片右侧「开通管理」 → 按需计费 → 确定
  1. SIS 有两个录音文件识别服务，必须分别开通。只开普通版会一直卡住。
  2. 极速版：用「桶名 + 对象 key」提交，靠服务授权委托读取私有桶，原生支持 mp3/m4a/aac/wav/opus，同步返回文本。← 我们要用这个。
  3. 普通版：用 data_url 提交，audio_format 只接受裸 PCM；实测对私有桶会返回「FINISHED 但零文本」。仅作兜底。
  4. 没开极速版会报 SIS.0004 not subscribe this service.
「实时语音识别」「一句话识别」「语音合成」都不用开。

服务授权（让 SIS 能读你的私有桶）

SIS 控制台 → 左侧「服务授权」 → 「对象存储服务授权」 → 按引导创建委托
  1. 委托名默认由系统创建（实测名为 agency_for_voice，委托方 op_svc_asr），不用手填。
  2. 只有主账号或有 Security Administrator 权限的账号能创建委托。
  3. 桶保持私有，不要改成公共读——授权就是为了让私有桶也能被 SIS 读到。
  4. 验证委托是否建好：npm run check:agency（列出账号下所有委托，并顺带校验项目 ID）。

建 OBS 桶

控制台 → 对象存储服务 OBS → 桶列表 → 右上角「创建桶」
配置项怎么填
区域华北-北京四（必须与 SIS 一致）
桶名称全局唯一，建议 privacy-sentinel-audio-8f3a（后 4 位随机）
存储类别标准存储（音频读写频繁，低频存储反而更贵）
桶策略私有（不要选公共读）
服务端加密 / 归档全关，省事也省钱

配生命周期（断网崩溃时的兜底）

进桶 → 基础配置 → 生命周期规则 → 创建 → 前缀填 tmp/sis/ → 规则：对象创建 1 天后 删除
代码里转写完成会立即 deleteObject，这条规则只是防止服务崩溃时留下孤儿对象。别把前缀写错成 tmp/，否则可能误删别的数据。

2拿 AK / SK 与项目 ID，填进 .env

控制台 → 右上角账号名 → 我的凭证 → 访问密钥 → 新增访问密钥
  1. 点「新增访问密钥」，下载 credentials.csv。AK/SK 明文只显示这一次，关掉窗口就找不回来了。
  2. 同一页面切到「项目列表」页签，找到「华北-北京四」那一行，复制右侧的项目 ID（不是项目编号，也不是账号 ID）。
  3. 打开项目根目录的 .env（没有就从 .env.example 复制），填这 7 个：
HW_AK=你的AccessKeyId
HW_SK=你的SecretAccessKey        # 只在 csv 里出现一次
HW_PROJECT_ID=华北-北京四的项目ID
HW_REGION=cn-north-4
HW_SIS_ENDPOINT=https://sis-ext.cn-north-4.myhuaweicloud.com
HW_OBS_BUCKET=privacy-sentinel-audio-8f3a
HW_OBS_ENDPOINT=https://obs.cn-north-4.myhuaweicloud.com
AK/SK 只进 .env，不要写进代码、不要发到对话里、不要提交 git。.env 已在 .gitignore 中；填完用 git status 确认它没被跟踪。

重启并自检

npm start                                  # 重启服务
curl -s http://localhost:8080/api/health    # 端口按你的实际值

返回里应该出现 "aiProvider":"huawei"，并且（配齐 SIS 后）音频能力为可用。若仍是 ark，检查 AI_PROVIDER=huawei 是否设置。

3跑验收脚本（A + C，不花钱）

这一段只验证凭证、桶名、区域、读写权限，不提交 SIS 任务、不产生费用：

npm run verify:sis
  • ✅ 上传临时对象成功 —— AK/SK 与桶写权限 OK
  • ✅ 能在 tmp/sis/ 前缀下列到刚传的对象
  • ✅ 删除后立即查不到 —— deleteObject 生效
  • ✅ tmp/sis/ 下无残留对象

任一项红叉，脚本会直接给出定位提示（见第 5 节对照表）。

4录 5–10 秒真实录音，跑完整链路

录什么

用手机录音机或电脑自带录音，安静环境下念一句，数字要逐个念清楚：

「我的手机号是 138 0013 8000，我的身份证号是 110105 19900307 1234」
  • 时长 5–10 秒即可；采样率 16kHz 最佳，44.1kHz 也能识别。
  • 格式用 .wav 或 .mp3（.m4a、.aac 也支持）。传到项目根目录，比如 录音.m4a。

跑端到端转写

npm run verify:sis -- --audio 录音.m4a
  • ✅ 转写来源为 huawei-sis-flash（极速版）或 huawei-sis（普通版兜底）
  • ✅ 拿到转写文本（脚本会打印原文，逐字核对是否准确）
  • ✅ 转写文本里识别出身份证号或手机号
看到 huawei-sis 且文本为空：说明走了普通版兜底，它用 data_url 读私有桶拿不到内容， 会返回「FINISHED 但零文本」。去开通「录音文件识别极速版」即可（本页第 1 步）。
都没匹配到数字：先确认念的是数字而非「幺三八」；再重录一段更清楚的。
强制指定通道：npm run verify:sis -- --audio 录音.m4a --mode flash（或 --mode standard）。

再从服务端接口验一次（确认 transcribeProvider）

node -e "const fs=require('fs');const b=fs.readFileSync('录音.wav').toString('base64');
fs.writeFileSync('payload.json',JSON.stringify({kind:'audio',dataUrl:'data:audio/wav;base64,'+b}))"

curl -s -X POST http://localhost:8080/api/analyze \
  -H "Content-Type: application/json" -d @payload.json

返回 JSON 里重点看这两项：

字段期望值
transcribeProvider"huawei-sis"。若是 "ark" 说明走了回退通道，SIS 没生效
transcript转写出的完整文本
items识别到的敏感信息条目（身份证/手机号）
audioDurationMs音频时长（毫秒）
前端页面上传音频后，在浏览器开发者工具的 Network → /api/analyze → Response 里同样能看到这些字段，不用每次都敲命令。

5到 OBS 控制台确认无残留

控制台 → 对象存储服务 OBS → 你的桶 → 对象 → 前缀搜索框输入 tmp/sis/ → 查询
  • 期望结果：空列表。转写完成后代码已在 finally 里删除对象。
  • 如果看到残留对象，说明某次请求在删除前崩了。用脚本一次清掉：
npm run verify:sis -- --purge
残留不为 0 时，交付材料里不要写「音频用完即删」——先查日志里的 [sis] 删除 OBS 临时对象失败，定位是哪一步失败，修好再跑一遍。

常见报错对照

报错关键词原因与处理
NoSuchBucket桶名拼错，或桶在别的区域（与 HW_OBS_ENDPOINT 不一致）
AccessDenied / 403账号未实名或欠费；或子账号没被授予该桶的读写权限
SignatureDoesNotMatchSK 填错。SK 找不回来，只能删掉重建访问密钥
InvalidAccessKeyIdAK 填错，或把 SK 填进了 AK 的位置
Cannot find module 'uuid'官方 SIS SDK 漏声明依赖，执行 npm i uuid
ENOTFOUND / ETIMEDOUT端点写错。要带 https://，且不能把桶名拼进 OBS 端点
504 轮询超时音频太长或 SIS 拥塞。先试 10 秒以内的小文件
